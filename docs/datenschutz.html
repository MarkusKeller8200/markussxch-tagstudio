Datenschutz

Kurz: TagStudio sammelt keine Nutzungsdaten, hat keine Telemetrie und kein Benutzerkonto. Deine Musik, Tags, Einstellungen und Zugangsdaten bleiben auf deinem Computer.

Was TagStudio auf deinem Computer speichert

  • Einstellungen, Sicherungen, Playlists, Protokolle und Plugin-Daten im Benutzerordner (~/.tagstudio.json, ~/TagStudio).
  • Zugangsdaten für Online-Dienste (z. B. Beatport, Discogs, Cloud-Speicher) nur, wenn du sie selbst einträgst – verschlüsselt im Schlüsselbund des Systems (Windows DPAPI bzw. macOS-Schlüsselbund), nie im Klartext und nie an das TagStudio-Projekt.

Verbindungen ins Internet

  • Update-Prüfung und Plugin-Katalog: TagStudio fragt bei GitHub nach neuen Versionen und Plugins (öffentliche Schnittstelle, ohne Anmeldung). Dabei sieht GitHub wie bei jedem Webseitenaufruf deine IP-Adresse.
  • Online-Plugins (MusicBrainz, Deezer, Beatport, Discogs, Spotify, Cloud-Abgleich …) verbinden sich nur, wenn du sie einschaltest und benutzt – und nur mit dem jeweiligen Dienst. Es gelten dessen Datenschutzbestimmungen.
  • Fehler melden öffnet das GitHub-Formular im Browser; abgeschickt wird erst dort, mit deiner eigenen GitHub-Anmeldung. Persönliche Angaben (Benutzerordner, E-Mail-Adressen, Schlüssel) werden vorher geschwärzt.

Diese Webseite

Die Seite liegt auf GitHub Pages, setzt keine Cookies und lädt nichts von fremden Servern. GitHub kann beim Aufruf technische Daten (z. B. IP-Adresse) protokollieren – siehe GitHub-Datenschutzerklärung. Die Download-Zahlen stammen aus den öffentlichen Zählern von GitHub und enthalten keine Personendaten.
